# Dashboard IT (vizualizační prototyp)

Tento projekt je čistě front-end (bez backendu). Čísla jsou záměrně dummy – cílem je ověřit layout, hierarchii a způsob prezentace klíčových IT metrik pro danou obchodní doménu/útvar.

## Jak spustit

- Otevři `index.html` v prohlížeči (stačí dvojklik).
- Alternativně: z projektu si otevři statický server (např. VS Code „Live Server“).

## Co lze snadno upravit

- Seznam domén: v `app.js` v poli `domains`.
- Widgety / metriky: v `index.html` (ID pro napojení do `app.js`).
- Styling: `styles.css`.
